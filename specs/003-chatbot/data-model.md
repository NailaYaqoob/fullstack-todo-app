# Data Model: AI-Powered Todo Chatbot

**Feature**: `003-chatbot` | **Date**: 2026-03-25

---

## New Entity: Conversation (message row)

Each row represents **one turn** (user message or assistant reply) in a conversation.
All messages for a thread share the same `conversation_id`.

### Table: `conversation`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid.UUID` | PRIMARY KEY, default `uuid4` | Row identifier |
| `conversation_id` | `str` | NOT NULL, INDEX | Groups messages into a thread |
| `user_id` | `str` | NOT NULL, INDEX | FK reference to Better Auth `user.id` |
| `role` | `str` | NOT NULL | `"user"` or `"assistant"` |
| `content` | `str` | NOT NULL | Message text |
| `created_at` | `datetime` | NOT NULL, default `utcnow` | Ordering field |

**Indexes**:
- `idx_conversation_user_id` on `conversation(user_id)` — fetch all messages for a user
- `idx_conversation_conversation_id` on `conversation(conversation_id)` — fetch thread

**SQLModel definition**:
```python
class Conversation(SQLModel, table=True):
    __tablename__ = "conversation"

    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    conversation_id: str = Field(index=True)
    user_id: str = Field(index=True)
    role: str                          # "user" | "assistant"
    content: str
    created_at: datetime = Field(default_factory=datetime.utcnow)
```

**Validation rules**:
- `role` must be `"user"` or `"assistant"` — enforced at application layer
- `content` must be non-empty — enforced at application layer
- `user_id` must match authenticated JWT `sub` — enforced at API layer
- `conversation_id` is a UUID string — generated by backend on first request

## Conversation Thread Lifecycle

```
First request (no conversation_id in request)
  → backend checks: SELECT conversation_id FROM conversation
                    WHERE user_id = ? ORDER BY created_at ASC LIMIT 1
  → found: reuse existing conversation_id
  → not found: generate new UUID, use as conversation_id

Each request:
  1. Load last 20 messages: SELECT * FROM conversation
                             WHERE conversation_id = ?
                             ORDER BY created_at DESC LIMIT 20
                             → reverse for chronological order
  2. Run agent with history + new user message
  3. INSERT user message row
  4. INSERT assistant reply row
  5. Return reply + conversation_id
```

## Context Window Strategy

The last **20 messages** (10 turns) are passed to the AI per request:

```python
# Fetch history (most recent 20, reversed to chronological)
stmt = (
    select(Conversation)
    .where(Conversation.conversation_id == conversation_id)
    .order_by(Conversation.created_at.desc())
    .limit(20)
)
rows = (await session.execute(stmt)).scalars().all()
history = [{"role": r.role, "content": r.content} for r in reversed(rows)]
```

Older messages remain in the database for history display but are not sent to the AI.
